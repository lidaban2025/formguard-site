How to Limit Google Forms Responses Automatically

Google Forms can stop accepting responses manually, but many signup forms need a simple automatic cap: close the form after 12 seats, 24 registrations, 100 survey entries, or any other response limit.

When a response limit helps

  • Course registration with a fixed number of seats.
  • Event signup where overflow creates support emails.
  • Internal request forms that should close after a quota is reached.
  • Volunteer or interview slots where the first N responses should reserve capacity.

Set up a response limit with FormGuard

  1. Install FormGuard from the Google Workspace Marketplace.
  2. Open the Google Form you want to control.
  3. Open FormGuard from the add-ons menu.
  4. Turn on Response limiter.
  5. Enter the maximum number of responses.
  6. Add a custom closed-form message for late visitors.
  7. Save settings.
FormGuard checks the current response count when you save settings and when new responses arrive. When the limit is reached, it closes the form and can email the owner.

What visitors see after the limit is reached

Visitors see your custom closed-form message instead of submitting another response. This is useful for waitlist instructions, next event links, or a simple note that registration is full.
